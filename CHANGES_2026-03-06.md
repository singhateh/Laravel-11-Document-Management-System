# Changes — March 6, 2026

## Viewer Access Grant API

Implemented the Viewer Access Grant feature, closing the highest architectural
gap between the StegoLock spec and the existing codebase. Owners can now share
decode access with specific users without exposing the document or its ciphertext.

---

## 1. Schema — `stego_document_grants` Table

**New migration**: `database/migrations/2026_03_06_000001_create_stego_document_grants_table.php`

```sql
CREATE TABLE stego_document_grants (
    id                  BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    stego_document_id   BIGINT UNSIGNED NOT NULL,  -- FK → stego_documents (cascade)
    viewer_user_id      BIGINT UNSIGNED NOT NULL,  -- FK → users (cascade)
    granted_by          BIGINT UNSIGNED NOT NULL,  -- FK → users (cascade), the owner
    created_at          TIMESTAMP NULL,
    updated_at          TIMESTAMP NULL,
    UNIQUE (stego_document_id, viewer_user_id)     -- one grant per viewer per doc
);
```

The unique constraint on `(stego_document_id, viewer_user_id)` is enforced both
at the DB level and returned to the caller as a **409 Conflict** via
`UniqueConstraintViolationException`.

## 3. New API Endpoints — Grant / Revoke

`app/Http/Controllers/Api/StegoDocumentController.php`

### `POST /api/stego/documents/{id}/grant`

|                |                                                                                         |
| -------------- | --------------------------------------------------------------------------------------- |
| **Auth**       | Sanctum token required                                                                  |
| **Ownership**  | 404 if the authenticated user is not the document owner                                 |
| **Body**       | `viewer_user_id` (integer, must exist in `users`)                                       |
| **Self-grant** | 422 if `viewer_user_id` equals the owner                                                |
| **201**        | `{ message, grant: { id, stego_document_id, viewer_user_id, granted_by, created_at } }` |
| **409**        | Viewer already has a grant for this document                                            |

```php
public function grant(Request $request, int $id): JsonResponse
{
    $stegoDoc = Auth::user()->stegoDocuments()->findOrFail($id); // owner check

    $request->validate(['viewer_user_id' => ['required', 'integer', 'exists:users,id']]);

    // ... self-grant guard, UniqueConstraintViolationException → 409
    $grant = StegoDocumentGrant::create([...]);

    return response()->json(['message' => 'Access granted.', 'grant' => [...]], 201);
}
```

### `DELETE /api/stego/documents/{id}/grant/{viewer_user_id}`

|                  |                                                         |
| ---------------- | ------------------------------------------------------- |
| **Auth**         | Sanctum token required                                  |
| **Ownership**    | 404 if the authenticated user is not the document owner |
| **Grant lookup** | 404 if no matching grant found                          |
| **200**          | `{ message: 'Grant revoked.' }`                         |

## 4. Updated `decode()` — Owner OR Granted Viewer

**Before** (owner-only):

```php
$stegoDoc = StegoDocument::where('user_id', $user->id)
    ->where('id', $request->stego_document_id)
    ->firstOrFail();
```

**After** (owner OR granted viewer):

```php
$stegoDoc = StegoDocument::where(function ($q) use ($user) {
        $q->where('user_id', $user->id)
          ->orWhereHas('viewerGrants', fn ($g) =>
              $g->where('viewer_user_id', $user->id)
          );
    })
    ->where('id', $request->stego_document_id)
    ->with('document')
    ->firstOrFail();
```

The service call always passes `$stegoDoc->user_id` (the **owner's** id) rather
than the caller's id, so DEK re-derivation remains correct regardless of whether
the caller is the owner or a granted viewer.

## 5. Routes

`routes/api.php` — two new routes inside the `prefix('stego')` group:

```php
// Grant viewer-decode access (owner only)
Route::post('/documents/{id}/grant', [StegoDocumentController::class, 'grant'])
    ->name('documents.grant')
    ->whereNumber('id');

// Revoke viewer access (owner only)
Route::delete('/documents/{id}/grant/{viewer_user_id}', [StegoDocumentController::class, 'revokeGrant'])
    ->name('documents.grant.revoke')
    ->whereNumber(['id', 'viewer_user_id']);
```

breaking all factory-dependent feature tests.
