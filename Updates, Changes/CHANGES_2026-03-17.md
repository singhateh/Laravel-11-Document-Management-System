This update includes critical fixes and improvements to access control, crypto service validation, and steganography pipeline hardening. Key changes address policy implementation, validation errors, and endpoint behavior to ensure a secure and consistent user experience.

## Key Additions

### Access Control Improvements
1. **Policy Stub Implementation**
   - Completed policy implementation for ShareDocumentPolicy
   - Completed policy implementation for NotificationPolicy  
   - Completed policy implementation for FileRequestPolicy
   - All policies now properly implement view, create, update, delete operations

2. **List Grants Endpoint**
   - Added `GET /api/stego/documents/{id}/grants` endpoint to StegoDocumentController
   - Returns all viewer grants for a specific stego document
   - Only accessible to the document owner
   - Grants include viewer and grantor user information with email and name

3. **Standardized Endpoint Behavior**
   - Fixed `show` method in StegoDocumentController to return 404 instead of 403 when accessing non-owned documents
   - Fixed `grant` method in StegoDocumentController to return 404 instead of 403 when accessing non-owned documents  
   - Fixed `revokeGrant` method in StegoDocumentController to return 404 instead of 403 when accessing non-owned documents
   - Fixed `listGrants` method in StegoDocumentController to return 404 instead of 403 when accessing non-owned documents

### Crypto Service Fixes
1. **Validation Order Fix**
   - Fixed validation order in CryptoService::decrypt method
   - Ensures IV validation happens before auth tag validation
   - Prevents incorrect error messages when multiple validation failures occur

2. **Test Improvements**
   - Updated CryptoServiceTest to use valid base64-encoded IV values in decrypt tests
   - Fixed tests for empty auth tag and invalid auth tag length to use valid IV inputs
   - Ensures all crypto service tests are consistent and reliable
