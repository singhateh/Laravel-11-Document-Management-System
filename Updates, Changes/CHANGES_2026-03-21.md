```php
// Added user management endpoints
Route::middleware(['auth:sanctum'])->group(function () {
    Route::get('/users', [Api\UserController::class, 'index'])
        ->name('api.users.index')
        ->can('viewAny', User::class);
    
    Route::put('/users/{id}/role', [Api\UserController::class, 'updateRole'])
        ->name('api.users.updateRole')
        ->whereNumber('id')
        ->can('update', 'App\Models\User');
    
    Route::get('/roles', [Api\RoleController::class, 'index'])
        ->name('api.roles.index');
    
    Route::get('/roles/{role}/permissions', [Api\RoleController::class, 'permissions'])
        ->name('api.roles.permissions')
        ->whereAlpha('role');
});
```

### Usage Instructions

#### Accessing Role Management
1. Log in with an admin or owner account
2. Navigate to `/users/roles` from the sidebar menu

#### Managing User Roles
1. View all users with their current roles
2. Click "Edit" to change a user's role
3. Select a new role from the dropdown menu (admin, owner, or user)
4. Save the changes

#### Viewing Role Permissions
1. Click on a role name to view its permissions
2. Permissions are organized by category
3. Each permission is displayed with a green badge
