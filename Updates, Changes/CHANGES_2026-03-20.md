# Changes — March 20, 2026

## File Upload Size Limit Increase

### Overview
Increased the maximum file upload size limit from 25 MB to 100 MB across all application components to support larger document and carrier image uploads.

---

## Frontend Changes

### 1. DragDropUploadModal.tsx
- Increased `MAX_FILE_SIZE_BYTES` from 25 MB to 100 MB
- Updated error message from "Some files exceed 25 MB" to "Some files exceed 100 MB"
- Changed description to "All file types allowed (max 100 MB per file)"

### 2. UploadModal.tsx
- Increased `MAX_FILE_SIZE_BYTES` from 25 MB to 100 MB
- Updated error message from "Some files exceed 25 MB" to "Some files exceed 100 MB"

### 3. Stego/Encode.tsx
- Added file type and size validation before adding carriers
- Added error messages for invalid file types or oversized files
- Updated description to "PNG, BMP or JPEG only (max 100 MB per file)"

### 4. stegolock-spa/pages/Encode.tsx
- Added file type and size validation before adding carriers
- Added error messages for invalid file types or oversized files
- Updated description to "PNG, BMP, or JPEG only (max 100 MB per file)"

---

## Backend Changes

### 1. Api/DocumentController.php
- Updated validation from `max:51200` (50 MB) to `max:102400` (100 MB)

### 2. Api/StegoDocumentController.php
- Updated validation from `max:20480` (20 MB) to `max:102400` (100 MB)

### 3. config/stegolock.php
- Changed `max_carrier_size_mb` from 20 MB to 100 MB

### 4. StoreDocumentRequest.php
- Modified the `maxUploadKilobytes()` method to set a fixed maximum upload size of 100MB (in KB)
- Added logic to use the smaller of the fixed limit or PHP's effective limit for safety

---

## PHP Configuration Changes

### php.ini (C:\Users\USER\.config\herd-lite\bin\php.ini)
- Set `upload_max_filesize = 100M` to allow larger file uploads
- Set `post_max_size = 100M` to match the upload limit
- Increased `memory_limit = 256M` to handle processing of larger files

---

## Verification

### Before Changes
- Maximum upload limit: 25 MB
- Error message when uploading 6.7 MB file: "A file failed to upload because it is larger than the server upload limit"

### After Changes
- Maximum upload limit: 100 MB
- 6.7 MB file uploads successfully
- Clear error messages for invalid file types and oversized files

---

## Usage Instructions

No changes to API endpoints or user interface interactions are required. The upload limit increase is transparent to users, with updated error messages providing clear feedback when file size or type constraints are violated.
