## Implementation Approach

### Decoding Architecture
The decoding process now follows an asynchronous pattern:
1. User initiates decode request
2. System creates a decode job and sets status to "pending"
3. Job runs in background, updating status to "in_progress"
4. On completion, status is set to "completed" and download path is stored
5. User can then download the decoded file from the UI

### Dynamic Segmentation
The new segmentation approach:
1. Calculates total capacity of all carrier images
2. Distributes payload evenly across all carriers based on their individual capacities
3. Ensures optimal PSNR by balancing data distribution
4. Provides better error messages when carrier capacity is insufficient

### User Experience
The updates focus on providing clear, real-time feedback to users:
- Visual status indicators for decoding progress
- Separate actions for decode and download
- Improved error messages with specific details
- Enhanced user selection interface
- Better responsiveness and accessibility
